# Makebee Website

The official website of **Makebee**, a software product studio building digital products, AI solutions, and business automation systems.

The website serves as Makebee's public-facing company presence, communicating what we build, showcasing selected products and work, and providing a direct channel for collaboration and enquiries.

---

**Makebee** is a software product studio focused on turning ideas into useful, scalable digital products.

We work across:

- Product Development
- Software Development
- AI Solutions

- Software Services

Our approach combines product thinking, engineering, design, and emerging technologies to build software that solves real problems.

---

## About This Repository

This repository contains the production frontend for the official Makebee website.

The site was developed from the approved Makebee design direction and preserves the brand's core visual language, including:

- Midnight navy and honey/gold colour system
- Makebee hexagon motif
- Premium editorial typography
- Dark and light themes
- Responsive layouts
- Accessible interaction patterns
- Performance-conscious animations
- GSAP-powered scroll experiences

The project is maintained by the Makebee frontend team.

---

## Tech Stack

| Technology | Purpose |
| --- | --- |
| React 19 | UI development |
| Vite 6 | Development and production tooling |
| Tailwind CSS 3 | Utility-first styling |
| JavaScript / JSX | Application development |
| GSAP | Animation and scroll-driven interactions |
| ScrollTrigger | Scroll-based animation control |
| Inter | Body and UI typography |
| Plus Jakarta Sans | Display and heading typography |

The website is currently a frontend application and does not require a dedicated backend.
